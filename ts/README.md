# sema TypeScript runtime

The TypeScript runtime: one zod schema per vocabulary word, generated by
`src/sema/tools/ts_generation/` from the same definitions as the Python
runtime. `runtime/` is generated; regenerate with
`scripts/regenerate_runtime_ts.sh`, which also formats with Prettier (the
single source of style) and runs the generated Vitest suite.

Needs Node 22 with npm (`nvm use 22`) and `npm install` in this folder.
